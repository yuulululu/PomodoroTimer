# 🎀 Pomodoro Timer

Pomodoro timer สีชมพูพาสเทล หน้าตาเหมือนเครื่องเล่น mp3 เขียนด้วย HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

## ฟีเจอร์

- 3 โหมดที่เปรียบเหมือนแทร็กเพลง
  - แทร็ก 01 โฟกัส 25 นาที
  - แทร็ก 02 พักสั้น 5 นาที
  - แทร็ก 03 พักยาว 15 นาที
- ปุ่มเล่น/หยุด, ย้อนโหมด, โหมดถัดไป และรีเซ็ตเวลา
- แถบความคืบหน้าบนจอ และแสดงเวลาที่แท็บเบราว์เซอร์
- เสียงเตือนเมื่อหมดเวลา แล้วเลื่อนไปโหมดถัดไปให้อัตโนมัติ
- timer คำนวณจากเวลาเป้าหมาย จึงไม่เพี้ยนเมื่อสลับแท็บหรือปิดจอชั่วคราว

## วิธีใช้งาน 1

1. ดาวน์โหลดหรือ clone โปรเจกต์นี้
2. เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย

```bash
git clone https://github.com/yuulululu/PomodoroTimer.git
cd pomodoro-timer
```

1. กดเข้าใช้งานที่เว็บไซต์ https://yuulululu.github.io/PomodoroTimer/
2. ใช้งานได้เลย

## ปรับแต่ง

**เปลี่ยนสี** แก้ตัวแปรที่ส่วน `:root` ใน `css/style.css`

| ตัวแปร | ใช้กับ |
| --- | --- |
| `--bg` | พื้นหลังหน้าเว็บ |
| `--body` | ตัวเครื่องเล่น |
| `--screen` | จอ LCD |
| `--accent` | ปุ่มเล่น และแถบความคืบหน้า |
| `--ink` | สีตัวอักษร |

**เปลี่ยนเวลา** แก้ค่า `minutes` ในอาร์เรย์ `MODES` ที่ต้นไฟล์ `js/app.js`

```js
const MODES = [
  { name: "โฟกัส",   minutes: 25 },
  { name: "พักสั้น", minutes: 5 },
  { name: "พักยาว",  minutes: 15 },
];
```

## แผนที่จะทำต่อ

- [ ] หน้าตั้งค่าเวลา และเก็บค่าด้วย localStorage
- [ ] เล่นเพลง mp3 ระหว่างโฟกัส
- [ ] Notification ของเบราว์เซอร์
- [ ] ทำเป็น PWA (manifest + service worker) ให้ติดตั้งบนมือถือได้
